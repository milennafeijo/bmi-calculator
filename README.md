# bmi-calculator
Calculadora de Índice de Massa Corporal (IMC) 

Meu primeiro projeto focado em lógica de programação com JavaScript. O objetivo principal foi aprender a trabalhar com dados inseridos pelo usuário e exibir resultados de forma dinâmica na interface.

Durante o desenvolvimento, trabalhei com operadores matemáticos para realizar o cálculo do IMC, utilizei estruturas condicionais como if e else if para classificar os resultados e criei funções para organizar melhor o código.

Também aprendi a manipular o DOM para exibir o resultado na tela, validar dados para evitar valores inválidos ou extremos e tratar a entrada do usuário, como aceitar altura sem ponto decimal.

Utilizei ferramentas de apoio como o Gemini Code Assist no Visual Studio Code para auxiliar na resolução de problemas, sempre buscando compreender e adaptar a lógica aplicada.
